# Lumina | Immersive Digital Experience

A high-fidelity React frontend built with Tailwind CSS v4, featuring immersive cinematic visuals and a custom "liquid glass" UI system.

## 🌌 Visual Direction
Lumina is designed as an atmospheric collective where technology meets quiet luxury. The interface acts as a series of optical layers—polished, precise, and immersive—floating over deep, abstract cosmic backgrounds.

## ✨ Key Features
- **Liquid Glass UI:** A custom-engineered CSS glassmorphism system using advanced masking, gradients, and a 12px backdrop blur for a high-end frosted aesthetic.
- **Cinematic Immersion:** Full-screen fixed video backgrounds that provide a dynamic, ethereal atmosphere.
- **Motion System:** Smooth entrance animations and scroll-triggered reveals powered by `motion/react`.
- **Premium Typography:** Integrated custom "Helvetica Regular" font-face for a clean, timeless editorial feel.

## 🛠 Tech Stack
- **Framework:** React
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [motion/react](https://motion.dev/) (Framer Motion)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🎨 Design Tokens
### Colors (Lumina Dark)
- **Surface:** `#141313`
- **Primary (Text/Action):** `#FFFFFF`
- **Glass Border:** Semi-transparent linear gradients (0.45 opacity to 0)
- **Selection:** `bg-white/20 text-white`

### Effects
- **Liquid Glass Blur:** `12px` (Backdrop Filter)
- **Glass Shadow:** `inset 0 1px 1px rgba(255, 255, 255, 0.1)`
- **Border Weight:** `1.4px` (Masked Gradient)

## 📦 Components
### 1. Immersive Video Background
A fixed-position, auto-playing video element that serves as the visual anchor for the entire experience.

### 2. Navigation Bar
A floating "liquid glass" header with blur-diffusion, providing access to Discover, Mission, Concierge, and Gallery sections.

### 3. Hero Section
Features high-impact typography with subtle motion offsets and staggered button reveals.

### 4. Liquid Glass Footer
A complex 12-column grid layout utilizing custom CSS masking for a "liquid" border effect, housing site navigation, brand description, and social connectivity.
